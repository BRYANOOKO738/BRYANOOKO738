## 🚀 About Me

I am a Chemical Engineering student with a strong focus on applying Artificial Intelligence to industrial process systems.

My work centers on:
- Intelligent process control using Reinforcement Learning  
- Simulation-driven training (Aspen + physics-based environments)  
- Predictive maintenance and fault detection using ML  
- Moving toward fully autonomous process plants  

I am particularly interested in bridging first-principles engineering with modern AI to build smarter, more efficient, and adaptive industrial systems.
